What's most relevant in this directory are:

* `latex/discrete_gauge_theory`: the latex and figures from my masters thesis "Discrete Differential Geometry in Homotoy Type Theory" (see [the official page for that](https://greg.langmead.info/writing/differential_geometry_in_hott/))
* `agda/manifold_equivalences.lagda.md`: Agda proofs in discrete differential geometry, including the equivalence of some polygons, and the start of a proof that the octahedron is equivalent to the 2-sphere.
